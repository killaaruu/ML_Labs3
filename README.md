5. Созданы отдельные отчёты и сохранены графики, примеры предсказаний, веса моделей и журналы обучения.

## Повторный запуск в Windows PowerShell

Активное окружение проекта — `.venv`. Все команды запускаются из корня репозитория.

```powershell
$env:TMP = "$PWD\.tmp"
$env:TEMP = $env:TMP
$env:MPLCONFIGDIR = "$PWD\.mplconfig"
$env:PYTHONUTF8 = "1"

.\.venv\Scripts\python.exe data\prepare_cifar10.py
.\.venv\Scripts\python.exe lab1\train.py --epochs 15 --workers 4
.\.venv\Scripts\python.exe lab2\train.py --epochs 15 --workers 4
.\.venv\Scripts\python.exe lab3\text_gen.py --steps 3000
.\.venv\Scripts\python.exe lab4\segmentation.py --base 32 --epochs 20 --lr 1e-3 --workers 0
```

Лаба 2 должна запускаться после лабы 1: она читает `lab1/results/metrics.json` для сравнения. Для генерации после обучения:

```powershell
.\.venv\Scripts\python.exe lab3\text_gen.py --generate --prompt "ROMEO:" --temperature 0.8
```

`workers 0` для лабы 4 выбран после того, как короткий запуск с четырьмя процессами не показывал прогресса; нулевой режим успешно прошёл и короткую проверку, и полное обучение. На этом компьютере подтверждён CUDA-режим, AMP включён автоматически. Перед повторным длительным обучением подключите ноутбук к питанию и включите режим максимальной производительности.

## Краткие пояснения

- **Лабы 1–2:** CNN по изображению 32×32 выбирает один из 10 классов. Во второй работе обучающие изображения случайно преобразуются; итоговое улучшение небольшое, но измеримое.
- **Лаба 3:** модель предсказывает следующий символ по контексту длиной 128 символов. Она усвоила стиль и структуру диалогов корпуса, но не гарантирует связный сюжет.
- **Лаба 4:** U-Net выдаёт класс для каждого пикселя. Pixel accuracy показывает долю верно размеченных пикселей, а mIoU усредняет пересечение и объединение областей по классам; низший IoU у узкого класса границы.

При интерпретации результатов учитывайте, что исходный код использует тестовый набор для оценки после каждой эпохи, а не отдельную validation-выборку. Это удобно для учебного сравнения и визуального контроля, но финальные значения не являются оценкой на полностью нетронутом holdout-наборе.
